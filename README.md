# By Matthew Thomas

Public website files for [bymatthewthomas.com](https://bymatthewthomas.com), presented through the Library of Zephyr.

Includes HTML, CSS, JavaScript, the website poetry catalog, and website images. Original manuscripts and source documents are not included.

## Local preview

Run `python3 -m http.server 8000 --bind 127.0.0.1` from this folder and open http://localhost:8000. No build is required.

This repository is a website snapshot. Updating it does not automatically deploy the live website.
